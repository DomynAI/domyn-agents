Event types

Every event is a BaseEvent (domyn.agents.core) whose event_type is an ExecutionEventType. This page uses the values, such as tool_start; in Python, compare with the enum member, such as ExecutionEventType.TOOL_START. How to consume them is in Events and streaming.

Fields​

FieldTypeDescription
event_typeExecutionEventTypeWhat happened.
authorstrThe agent the event belongs to; user for inputs.
contentlist[Part]Text and other parts. See Parts.
actionactionThe call the event is about, for tool and agent events. See Actions.
is_partialboolMore pieces of the same output follow.
error_codestr | NoneOn errors: a short code, such as the exception type.
error_messagestr | NoneOn errors: the description.
metadatadictType-specific data, listed per type below.
need_feedbackboolThe event is a question to the user, and the turn ends with it.
event_idstrUnique id of the event.
conversation_idstrThe conversation.
turn_id, interaction_idstrIdentify the turn the event belongs to. A turn resumed after an approval keeps both.
timestampdatetimeWhen the event was created.

Parts​

FieldDescription
textText for the user.
thoughtThe agent's reasoning, or a status line, not meant as the answer.
code, html, chart, rich_text, link, file, metadata, guardrail_resultStructured parts, for interfaces that render them.

Actions​

ClassOnFields
AgentActionagent_start, agent_call, a remote agent's agent_endname (the agent), parameters (the task, or the agent's own invocation parameters), thought
ToolActiontool_start, tool_update, tool_end, tool_error, a local team member's agent_endname, parameters, thought, call_id, observation (the result, on tool_end and tool_error)
FeedbackActiontool_needs_feedback, tool_feedbackas ToolAction, plus approval_type, approve, remember_scope, remember_pattern; parameters is a list of name–value pairs that can be edited
AuthenticationActiontool_needs_feedbackas ToolAction, for an MCP tool whose OAuth credentials must be renewed before it runs

Every action also has an optional message.

Emitted by the runner​

Agents​

TypeWhenCarries
agent_startAn agent starts its part of the turn: the root agent first, then each team member it hands off to.action: AgentAction with the task; content: the task as text.
agent_callAn agent hands off to a team member. Followed by that member's agent_start.action: AgentAction naming the member, with its arguments and the reason in thought.
agent_endAn agent finishes. For the root agent, the last event of the turn.For a team member, its answer in content and its final call in action. Empty for the root agent.

Model calls​

TypeWhenCarries
llm_startBefore each model call.metadata["context_usage"]: message_tokens and tool_definition_tokens (estimated), correction_tokens (the provider's count of the last request minus the estimate of it, 0 without a count), context_window, threshold_tokens and strategy, each None when it does not apply. threshold_tokens is set only when a compaction can happen; content: a status line.
llm_endAfter each model call.content: a status line and, for a tool_use_thought agent, the model's reasoning as a thought part.
responseThe reply, when it is not streamed; text a streaming tool shows right away (is_partial); a reply forwarded unchanged with FORWARD_VERBATIM (metadata["forward_verbatim"]); the message of a hook that stops the turn; a question to the user (need_feedback).content: the text.
response_tokenA piece of a streamed reply, for an agent with stream=True.content: the next piece; is_partial is True.
external_partContent pushed into a running turn with Runner.push_parts, from outside the agent.content; the model sees it only when its metadata marks it visible.
llm_provider_errorThe model's API failed, with the react planner only.error_message.

Tools​

TypeWhenCarries
tool_startThe model called a tool.action: ToolAction with the arguments and the thought.
tool_updateA streaming tool reported progress with UpdateToolResult. Not shown to the model.content[0].metadata: the data the tool yielded.
tool_endThe tool returned. Also when a call was refused at the approval gate: the refusal is the result.action.observation: the result.
tool_errorThe tool raised.error_code: the exception type; error_message and action.observation: its message.
tool_needs_feedbackThe tool needs approval before it runs. The turn ends with it.action: FeedbackAction for the pending call; metadata: approval_subject, approval_scopes, approval_pattern, approval_parts.

Hooks​

TypeWhenCarries
hook_startBefore a hook runs.metadata["hook_name"].
hook_updateA hook emitted content without finishing.content, metadata["hook_name"].
hook_endA hook finished.content it emitted, metadata["hook_name"].
hook_errorA hook raised.error_code: the exception type; error_message; metadata["hook_name"].

Compaction and errors​

TypeWhenCarries
context_compaction_startThe conversation is about to be shortened: the request reached the threshold, the provider rejected it as too long, or a compaction was requested.metadata: tokens_before, threshold_tokens and rejected (the provider rejected the request), or requested: True.
context_compactedThe compaction finished.metadata: changed (something was removed or summarized). At the threshold, also tokens_before, tokens_after, threshold_tokens and sufficient (the result fits under the threshold); on request, requested: True, events_dropped and tokens_saved.
error_occurredThe agent could not continue. The last event of the turn.error_message; content: a description, from a planner; error_code, from the runner, such as RequiredSkillUnavailable.

Accepted as input​

These are passed to Runner.run() as user_input.

TypePurpose
user_inputA message from the user: content with its text.
tool_feedbackThe answer to a tool_needs_feedback: its action, with approve set and, optionally, edited parameters and a remember_scope. See Tool approvals.
compaction_requestedAsks for a compaction now, instead of waiting for the threshold. The stream is only context_compaction_start and context_compacted (only the latter, with changed: False, for a planner that cannot compact), and the request is not added to the conversation. See Context compaction.
